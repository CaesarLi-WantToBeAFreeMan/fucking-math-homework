## Definition

> **Domain** is **all values** of `x` that make the function valid/defined.

## Main idea for finding domains

| scenario | solution | example |
| :-: | :-: | :-: |
| **denominator cannot be 0** | $\text {denominator} \neq 0$ | $f(x) = \frac {1} {x - 2} \rightarrow x \neq 2$ |
| **even roots cannot contain negative numbers** | $\text {base} \geq 0$ | $f(x) = \sqrt {x - 1} \rightarrow x \geq 1$ |
| **logarithm input must be positive** | $\text {base} > 0$ | $f(x) = \ln {x - 1} \rightarrow x > 1$ |

## Domain of common functions

| function | domain |
| :-: | :-: |
| $\sqrt {x}$ | $x \in [0, \infty)$ |
| $\ln {x}$ | $x \in (0, \infty)$ |
| $\arcsin {x}$ | $x \in [-1, 1]$ |
| $\arccos {x}$ | $x \in [-1, 1]$ |
| $\arctan {x}$ | $x \in \mathbb {R}$ |
| $\arccot {x}$ | $x \in \mathbb {R}$ |
